Capture mode control: round 2

Pick A, B or C. Every frame draws only the elements the desktop pane engine can draw. Pane strings are pt-BR; annotations are English.

The rule, for all three: changing the mode affects only questions captured from that moment on. It never hides, closes, re-files or re-sorts an open question. A question keeps the behaviour it was captured with; a session already paused stays paused until its question is answered.

Reading order: the header title and counter, then the mode control above the hairline, then the question tree below it. Mock only: nothing here is clickable.
